# 分析工具：从数据到决策

两个工具配合使用：**切身利益卡尺** 用于度量数据质量，**TRI 计量仪** 用于映射成功可能性。

---

## 工具 4 · 切身利益卡尺（Skin in the Game Caliper）

### 概念

> **切身利益（skin in the game）**：是指市场给你的某种有价值的反馈，作为其确实对你的创意感兴趣的证据。

其中 "game"（游戏）隐喻存在输赢概率的某些活动，"skin"（皮肤）隐喻该游戏中某些具有价值的东西——金钱、时间或声誉。

**这是本书的核心概念，它会反复出现。**

### 为什么它决定一切

对比两种情形：
- 自认为你的企业家朋友会大获成功因而鼓吹他辞职创业 → **这是一回事**
- 拿出 1 万美元投资他的新公司以示支持 → **完全另一回事**

因为对于后者，如果朋友创业失败，你会失去 1 万美元——**这就是切身利益**。

**人们喜欢发表意见、给人建议，而且大多数人这样做时没有想过自己是否是利益相关方**，因为无论如何他们都没有什么可失去的，也没有什么可获得的。

### 完整的计分表

**0 点（没有切身利益 = 没有点数）**

| 类型 | 说明 |
|---|---|
| 意见 | 不管是谁的——你自己的、别人的、专家的、焦点组的，**一律 0 点** |
| 点赞、喜欢 | 无脑点击非常容易 |
| 反对、投票 | 同上 |
| 转发、分享 | 同上 |
| 评论 | 同上 |
| 浏览、观看量 | 同上 |
| OPD | 由其他人在其他时间为其他目的收集的数据，不计点 |

> 在线上社交媒体、投票和所有类型调查中给出的喜欢、点赞、反对、转发、评论等，我也都分配了 0 点。**无脑地点击喜欢、发表评论或写条推文是相当容易的。总之，在我看来，没有切身利益就没有点数。**

> 这就是为什么在切身利益卡尺上**意见的点数为 0** 的原因，**不管是谁的意见都一样**。

**有价值的切身利益**

| 类型 | 估值 | 说明 |
|---|---|---|
| 已验证的电子邮箱 | **1 点/个** | 必须是拥有者确实有定期检查和使用的一个真实邮箱，而不是被迫提供时给出的自己不会用的邮箱 |
| 已验证的电话号码 | **10 点/个** | 比邮箱多得多，因为大多数人在给他人自己的电话号码时的谨慎程度要高很多 |
| 用户投入的时间 | **1 点/分钟** | 愿意花 30 分钟倾听产品介绍 = 30 点 |
| **真金白银** | **1 点/元** | "金钱有话说，意见靠边站" |

### 使用规则

- 把货币替换为当地货币并相应调整，**但不要过于追求精确**——不要设"邮箱 0.4 点""电话 3.7 点"这种值。
- **用不同数量级来区分重要性不同的事项**，用直觉和经验相结合来指引判断。
- **对"无利益 0 点"与"有利益"的清晰分隔，远比点数的精确更重要。**
- 要确保分配相对价值时是真实、客观、合理的：客户支付 50 美元订金的点数**应该**比他们提供一个已验证邮箱**多得多**。

### 综合示例：双队记

| | 团队 A | 团队 B |
|---|---|---|
| **展示** | YouTube 视频演示，14 万浏览量、2 万个赞、100 个反对，评论全是"真了不起！""绝佳的创意！" | 2 分钟视频展示功能 + 400 美元在线广告 |
| **触达** | — | 一星期内 8 000 人完整观看 |
| **第一个动作** | — | 视频结尾提供邮箱可收到上市通知 → 获得 120 个邮箱，其中 40 个未验证，**80 个有效** |
| **第二个动作** | — | 一星期后给这 80 人发邮件，提供以 125 美元（5 折）购买预售版的机会 → **收到 20 个订单** |
| **切身利益点数** | **0 点** | **2 580 点** |

团队 B 的计分明细：

| 环节 | 计分 | 说明 |
|---|---|---|
| 400 美元广告 → 8 000 次浏览 | **0 点** | 浏览没有点数。但这条数据可推出单次浏览获取成本 ≈ 0.05 美元 |
| 8 000 次浏览 → 80 个已验证邮箱 | **80 点** | |
| 80 个邮箱 → 20 个 125 美元订单 | **2 500 点** | 20 × 125 |
| **合计** | **2 580 点** | |

**关键结论**：

> 团队 A 甚至没有告诉我们他们为了得到这 14 万浏览量到底花了多少时间和广告费。

> 很可能团队 A 的创意是"正确的它"，而且将取得巨大的成功。他们有很多令人印象深刻的数字可以分享，但我**只有在看到真实数据时才会信服**。

> **不是所有数据都"生而平等"，就算 YODA 也不例外。团队 A 专注于数量，而团队 B 专注于质量。通常来说，数据的质量胜过数据的数量，而且附带大量切身利益是数据质量较高的重要标志。**

**注意团队 B 做得好的三个细节**：
1. 给出了数字**以及评估数字的上下文**（花了多少钱、多少人完整观看）
2. 主动剔除了未验证的邮箱（120 → 80）
3. 提供了**逐级转化**的完整链条，而不是单一终值

## 工具 5 · TRI 计量仪（"正确的它"计量仪）

### 概念

> **TRI 计量仪**：一个用于映射出并可视化地呈现出预型试验结果的工具，可帮助判断一个创意有多大的可能是"正确的它"。

### 为什么是 5 级刻度

刻度从 **10%** 开始，以 **20% 为增量**直到 **90%**：

| 刻度 | 成功可能性 | 含义 |
|---|---|---|
| 非常有可能 | 90% | |
| 有可能 | 70% | |
| 50/50 | 50% | 尚无定论 |
| 不可能 | 30% | |
| 非常不可能 | 10% | |

**为什么不是 7 级或 10 级，也不是从 0% 到 100%？**

- 增加层级只会让工具更复杂，**它所提供的精度也将超出我们的试验工具和对象所能支持的范围**
- 会产生一种**不适宜的确定感**
- 我们面对的是不确定的市场和人们的行为，非常难以量化。62.7% 与 63.3% 之间的差异在物理化学中是既精确又相关的，在这里不是

作者引用了苏斯博士《你要去往多么美妙的地方》："那么，你会成功吗？会！一定会。你有 **98.75%** 的可能性会成功。"——这样的句子总会让他笑容满面，因为他无法给出任何类似 98.75% 的保证。

> 如果你正确地应用本书的工具和技术，则可以大大提高你的成功概率，**或许能获得接近 80% 的保证**。

### 核心比喻：创意审判中的举证责任倒置

在美国刑事法庭上，除非已被证实有罪，否则被告将被认为是无辜的，举证责任由检方承担。

**但当我们把刑事律法换成市场规律并用于"审判"一个创意时，则正好相反：我们要先假设创意是"有罪"的，即会在市场上失败的"错误的它"。**

我们的工作是提供足够多的"确凿证据"，让"陪审团"改变态度转而支持该创意。

> "非凡的主张需要非凡的证据。"——卡尔·萨根

作者把它改成：**"非凡的主张需要充足证据以支持特例。"**

市场这个"法庭"会接受的唯一证据就是**与切身利益相关的 YODA**。而我们能获取 YODA 的唯一方式就是进行预型试验。

### 数据 → 刻度的映射方法

对每次试验，先问这个问题：

> **如果我们的市场参与假说为真，该预型试验有多大的可能性产出此数据？**

然后按下表映射：

| 数据 vs 假说预测 | 刻度 |
|---|---|
| **大大超过**假说的预测 | 非常有可能（90%） |
| **达到或略微超过**假说的预测 | 有可能（70%） |
| **略低于**假说的预测 | 不可能（30%） |
| **远低于**假说的预测 | 非常不可能（10%） |
| 数据**模糊的、可能已损坏的或难以诠释的** | 50/50，**或者选择丢弃** |

> 毕竟，即使在科学界也并非所有试验都能产出干净可靠的数据。

### 隔日寿司的完整示范

设定：总共有 100 盒寿司在售，把其中一半（50 盒）改为隔日寿司。午餐期间学生总共购买 40 盒预装寿司。

| 成果 | 隔日寿司售出 | 占比 | 刻度判定 | 理由 |
|---|---|---|---|---|
| **A** | 0 盒 | 0% | **非常不可能** | 假说预测 8 盒，实售 0。如果隔日寿司是"正确的它"，怎么可能一盒都卖不出去？ |
| **B** | 2 盒 | 5% | **非常不可能** | 有两个人能接受略不新鲜的寿司，但离 20% 预测值差距不小。除非准备好大幅调整商业模式和预期 |
| **C** | 6 盒 | 15% | **不可能** | 提供了证据证明某种可行市场或许存在，但该市场并未达到预测业务成功所需的规模 |
| **D** | 8 盒 | 20% | **有可能** | 这正是假说市场的底线，完全达到了确认假说所需的最低要求 |
| **E** | 16 盒 | 40% | **非常有可能** | 超出预期。"如果隔日寿司是'正确的它'，那么 40 盒能卖出 16 盒是可能的吗？"——可以很自信地回答非常有可能 |
| **F** | 2 盒 | 5% | **50/50 或丢弃** | 数据值得商榷：学校日报当天刊登了食用生鱼片风险的头版文章 |
| **G** | 30 盒 | 75% | **丢弃** | 试验当天一大群参加大学旅行的日本高中生来到咖啡馆——非正常情况。**必须注意别自欺欺人** |

**注意成果 F 和 G 的处理**：这不是"灵活诠释"，而是**基于已知的混淆因素做保守处理**。F 有明确的污染源（负面报道）→ 降级为 50/50 或丢弃。G 有明确的异常人群（日本高中生团）→ 丢弃而非欢呼。

**反过来也要警惕**：成果 E（40%）是超出预期的好结果，作者仍然先问"如果这是正确的它，这个结果是可能的吗？"——**先检验合理性，再接受结论**。

### 硬性规则

1. **单次试验永远不够。**
   > 我要先明确地告诉你：**只有一次试验是不够的，无论你认为一次试验的结果多么有说服力，一次试验都是不够的。**

2. **至少 3～5 次试验。**
   > 根据我的经验，你需要设计和运行**至少 3～5 次试验**，而且如果执行该创意会涉及重大风险或重大投资，例如，辞职或是把公司资金全押上，那就需要再多进行几次试验才行。**试验次数应该与投资和失败后果即你的切身利益的大小成正比。**

3. **为什么单次不够**：有很多潜在因素都可能导致试验失效。如果你已经意识到结果可能受到某些因素的影响，可以优化甚至抛弃这些数据，但**我们不可能知道或考虑到所有可能导致数据被扭曲或破坏的情况**。
   > 新弓箭手可能第一箭就射中靶心，而老弓箭手却只会偶尔失手。这也是我们需要往 TRI 计量仪上"多射几箭"的原因。

4. **底部永远有市场失败律的黑色大箭头。**
   它提醒我们：大多数新创意都将在市场上失败。**只有多次一致的正面结果才能平衡和抵消市场失败律的预测。** 三个正向结果是否足以平衡？需要结合投资规模判断。

5. **只有精心设计和亲自执行的试验产生的真实数据才有资格标注。**
   意见或其他人用其他方法在其他时间完成的市场研究**不应作为依据**。箭头必须只包含与切身利益相关的 YODA。

## 结果诠释：创意的典型演化路径

用"拳击"比喻——与失败之兽在"格斗场"大战几个回合。

### 第一回合：迎头痛击

除非运气特别好，做过几次试验后，**创意 1 的第一迭代**在 TRI 计量仪上大概率是这样的：

```
非常不可能   不可能    50/50    有可能    非常有可能
   (10%)      (30%)     (50%)     (70%)      (90%)
     │          │         │         │           │
  ◄──┤          │         │         │           │
  ◄──┤          │         │         │           │
     │       ◄──┤         │         │           │
     │          │      ◄──┤         │           │
```

**这是最常见的场景，不是异常。** 如果你是新手，这会让你感到震惊、受伤和迷惑，但别因此影响士气和情绪。

**两点安慰**：
1. 大多数人都认为自己的创意毫无疑问是"正确的它"，结果却惨遭碾压，所以在最开始遭受打击很正常。
2. 想一想如果不经测试直接闷头推进会损失多少。奋斗几个月、投入大量资金开发营销后，才发现创意一直是"错误的它"，这一记重拳可能直接把你击倒。**当下在试验上的小投入可以免去以后的大痛苦。**

**第一回合，失败之兽胜出。** 更合乎逻辑也不那么痛苦的做法是乖乖回到绘图板前，应用试验中学到的经验调整创意。

### 第 2～4 回合：有得有失

对原始创意做些许调整，每个变种（创意 2、3、4）各进行几次测试：

```
非常不可能   不可能    50/50    有可能    非常有可能
   (10%)      (30%)     (50%)     (70%)      (90%)
     │          │         │         │           │
  ◄──┤          │         │         │           │ 创意1
     │       ◄──┤      ◄──┤      ◄──┤           │ 创意2
     │          │         │      ◄──┤           │ 创意3
     │          │         │      ◄──┤           │ 创意4（37%）
     │          │         │         │           │
```

创意 4 已命中"有可能"区域（约 37%）。这是很好的信号——说明你正在加深对市场的理解并做出相应调整，**逐渐靠近"正确的它"**。

### 第 5 回合：连续命中几记好拳

以创意 4 为起点再调整，得到创意 5，进行 3 次试验，箭头全部指向"有可能"或"非常有可能"：

```
非常不可能   不可能    50/50    有可能    非常有可能
   (10%)      (30%)     (50%)     (70%)      (90%)
     │          │         │         │           │
     │          │         │      ◄──┤           │
     │          │         │         │        ◄──┤
     │          │         │         │        ◄──┤
```

如果开发这个创意需要大笔投资和重大承诺，希望再提升信心，于是用创意 5 再做 3 次试验，第二组用加粗箭头表示：

```
非常不可能   不可能    50/50    有可能    非常有可能
   (10%)      (30%)     (50%)     (70%)      (90%)
     │          │         │         │           │
     │          │         │      ◄──┤           │
     │          │         │      ◄══╡           │ 第二组
     │          │         │         │        ◄══╡ 证实第一组
     │          │         │      ◄══╡           │
```

**即使两组结果一致，依然不能对那个黑色大箭头视而不见**，因为市场失败律仍然有可能出其不意地袭击我们。

### 汇总视图

把创意 1 到创意 5 的所有试验结果映射到同一个 TRI 计量仪上，可以看到清晰的**渐进改善轨迹**。

**代价**：总共基于 5 个不同创意（或相似创意的不同改版）运行了 12 次预型试验。听起来次数很多，但**使用预型技术最多只需要花费几个星期的时间，比大多数团队用在编写基于 OPD 的业务计划书的时间还要短。**

## 完整案例：BusU 的 5 次试验

### 试验 1

```
xyz1：从旧金山通勤至山景城且听说过 BusU 的谷歌员工中，至少有 40% 的人会访问我们的网站并提交电子邮箱以获取课程安排的信息。
```
做法：经由列表管理员贝丝，向 100 名谷歌员工发邮件。
结果：4 小时内 88 人访问网站，**62 人填写表格（62%）**，远超 40% 预测。

**但作者没有直接记为"非常有可能"**，而是：
> 当我更仔细地检查这些数据时，我注意到提交表格的人几乎都在询问该服务是不是免费的……这时我才意识到我们应该在邮件或网站上把费用的事情讲得更清楚一些，因为谷歌的员工们早已习惯了享受免费的餐食、按摩和很多其他福利。

**判定：保守评定为"有可能"**（而非"非常有可能"），因为邮件中未提及 3 000 美元价格，受访者可能误以为免费。也可以更保守评为 50/50 或直接作为坏数据抛弃。

> 不管是什么创意想要在市场上得到超过 60% 的人回应都是极为少见的，我决定接受这一结果。

### 试验 2（修正后）

调整邮件和网站，清楚说明学费 3 000 美元、不适用谷歌教育补贴。再发 100 封。
结果：42 人访问网站，**22 人提交表格（22%）**——约为初始估计 40% 的一半。

**判定：可以接受**。
> 22% 的回应这个结果大概只有我们初始估计值 40% 的一半。但考虑到仍有 22 人愿意自掏腰包为此课程支付 3 000 美元的学费，因此我判定这个结果实际上非常不错。

> **我们这是在调低期望值吗？不！我们是在测试、校准和调整我们的初始假说。** 我们得到的回应率确实降低了一些，但回应的那些人可都是愿意投入自己更多的切身利益的人。

由此衍生出两个调整方向：
- **xyz1A**：把预期从 40% 下调到 20%，保留 3 000 美元价格
- **xyz1B**：保留 40% 预期，把学费降到 1 000 美元

### 试验 3（xyz3A）

期间收到谷歌员工鲍勃的邮件，自愿免费讲授机器学习课程。调整假说：
```
xyz3A：从旧金山通勤至山景城的谷歌员工中，至少有 10% 的人会支付 300 美元，参加由一名谷歌员工执教的一个星期的"机器学习入门"巴士课程。
```
成本测算：40 座巴士包车（含司机）约 1 000 美元/天或 5 000 美元/星期。若获至少 20 人注册（每人 300 美元），即可覆盖巴士租赁成本。
做法：向 200 名谷歌员工发邮件。
结果：不到两天，**48 人注册并付费**，另有 8 人候补。参与率 **24%**，远超 10% 的估算。银行账户进账 **14 400 美元（= 14 400 切身利益点）**。

### 试验 4～5（复购测试）

首期课程结束（35 人完成，3 人退款、2 人迟到错过）。**不问"你是否会再参加"**这类假设性问题，而是给出两个涉及切身利益的实际选择：
- 选项 1：花 3 000 美元参加 10 个星期的完整课程
- 选项 2：花 300 美元参加 1 个星期的下一堂课

两天后的数据：
- **21 人注册第二套课程**（超过一半学生愿做回头客）
- **没有人**报名 3 000 美元的 10 星期课程
- 反馈：晚上上课太难跟上，因为经过一整天工作后很疲惫；授课老师也承认晚上上课难度高很多

### 最终结果

```
YODA1：在 600 个样本中，132 位（22%）从旧金山通勤至山景城的谷歌和领英工程师
       支付了 300 美元参加 1 个星期的 BusU 人工智能课程。
       → 对应的切身利益约 40 000 美元（300 × 132）

YODA2：在学完 1 星期 300 美元课程的 132 位学生中，没有人报名 3 000 美元的 10 星期课程。

YODA3：在学完 1 星期课程的学生中，48% 报名了相同价格的另一个 1 星期课程。

YODA4：在报名的学生中，约 12% 会错过第一节课并要求退款。

YODA5：89% 的学生更喜欢只在早上上课。
```

**决策**：放弃 3 000 美元/10 星期的课程（创意 1），专注 300 美元/1 星期的课程（创意 2），并微调：正式授课限制在早上通勤时段，夜间时段用于非正式交流与讲师问答。

### 这个案例的 4 条注意事项

1. **附带切身利益的 YODA 让融资变得容易。** 展示的是实际成本、实际收入、实际利润，以及"上过一堂课的学生中有 48% 又购买了一堂课"这样的硬数据——而不是用希望、炒作和幻想版"五年财务预测"堆砌的商业计划。
2. **这是虚构场景，但基于真实故事。** 所描述的一切都是合理且可行的。
3. **案例以大团圆结局收尾，但并非创意的第一个版本。** 如果原封不动全力执行 3 000 美元/10 星期的原始计划，BusU 必将失败。**最初的 BusU 创意是"错误的它"，我们是通过测试和调整发现了"正确的它"版本。**
4. **顺序和结果会因案例不同而不同。** 目标始终是：从粗略创意 → 可验证假说 → 试验 → 数据 → 基于数据的下一步决策。
