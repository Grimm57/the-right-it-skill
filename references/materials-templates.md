# 预型物料模板

阶段 4 的产出。**核心原则：物料必须把切身利益做成可观测的动作**（提交邮箱 / 付定金 / 扫码 / 留电话），绝不能只是"点赞""关注""感兴趣"。

所有物料在投放前必须过一遍"合规检查"（见文末）。

### 1.2 广告文案范式

**搜索广告（3 组变体，用于 A/B）**

```
标题1（≤30字）：{品类}｜{核心收益带数字}
标题2（≤30字）：{目标人群}的{痛点}，{解决方案}
描述（≤80字）：{一句话说明}。{价格}。{动作}。
```

**社交广告（3 组变体）**

```
【变体 A — 痛点切入】
{目标人群}是不是经常遇到{具体痛点}？
{产品}能做到{核心收益，带数字}。
{价格} → {动作 CTA}

【变体 B — 结果切入】
{具体结果，带数字}。
{产品}用{方法}做到这一点。
现在预订：{链接}

【变体 C — 身份切入】
写给{目标人群}：{一句话价值主张}。
{可信度锚点：谁在做 / 已有多少人}
{动作 CTA}
```

**关键规则**：
- 三组变体**只改一个变量**（标题 / 价格 / CTA），否则无法归因
- 广告文案里的**价格必须在落地页首屏可见**，否则会产生 BusU 那种"以为免费"的污染数据
- 记录每个变体的**曝光数、点击数、提交数**，才能算 CAC

### 1.3 坦白页 / 致谢文案

**假门预型使用后必须提供**。三个版本按场景选：

**版本 A — 坦白 + 补偿（线下敲门场景）**

> 你好，抱歉打扰你。那扇门后面其实还没有书店——我正在做一个小测试，
> 想看看这条街上到底有多少人会对古董书店感兴趣，而不是只听大家的意见。
> 你刚刚敲门，对我来说就是最有价值的一个数据点。
> 这个给你，算是一点心意：{补偿物，如 10 元购书券 / 一本小书}。
> 谢谢你，真的。

**版本 B — 坦白 + 预订队列（线上提交邮箱场景）**

> **谢谢你的关注。**
>
> 我得坦白一件事：{产品名}目前还**没有正式发布**，我正在做一个小范围的测试，
> 想搞清楚到底有多少人真的需要它——不是随口说"听着不错"，而是愿意留下联系方式。
> 你提交的邮箱就是这样的证据，谢谢你。
>
> 作为回报：{免费样品 / 内测优先权 / 上线折扣码}。
> 如果最终决定做，你会是第一批知道的人；如果决定不做，我会在这封邮件里明说。

**版本 C — 支持退款声明（涉及任何预付的场景）**

> 关于你支付的 ¥{金额}：如果{产品名}最终没有上线，
> 你会在 {N} 个工作日内收到**全额退款**，不需要理由，不需要你主动申请。
> 我不会用一个还不存在的东西占用你的钱。

## 2. 假面预型物料

适用于假门被禁用（医疗/健康/金融）或需要学习交付流程的场景。

### 2.1 交付话术

```
[开场 — 主动确认预期]
"你好，{称呼}。先说清楚：我们现在规模还小，
{N} 天/周内会把 {交付物} 交到你手上，价格为 {价格}。
在这之前你有什么疑问，现在问我最方便。"

[处理"你们靠谱吗"]
"我理解。我们目前 {规模描述}。
你可以先看 {证据物：已有客户的反馈 / 样品 / 现场演示}，
或者先要一份 {最小交付物} 试试，不用一次性付全款。"

[交付过程 — 边做边学]
（这里是假面预型的核心：你在交付的同时记录
  流程里有哪些环节是你没预料到的）

[收尾 — 换取切身利益]
"如果你觉得可以，{下一步动作：付定金 / 签约 / 预约下次}。
另外，方便留个电话吗？（电话 = 10 点切身利益）"

[记录]
时间戳 / 客户画像 / 提出的问题 / 价格敏感度 / 交付耗时 / 意外环节
```

### 2.2 最小交付方案设计

假面的关键：**承诺的每一件事都必须真的做到**（CarsDirect 亏本交付了那 4 辆车）。

| 承诺 | 最小可交付版本 | 成本上限 |
|---|---|---|
| {核心承诺} | {手工/外包/临时方案} | ¥__ |
| {次级承诺} | {可延后或简化} | ¥__ |

**红线**：不得承诺你无法在承诺时间内真实交付的东西。**假面 ≠ 骗局，区别就在于"有人回应、有事情发生、人们或许还真能得到他们想要的东西"。**

### 2.3 答疑清单

预先准备客户最可能问的 8～10 个问题及答案，避免现场卡壳。

```markdown
| # | 可能的问题 | 回答要点 |
|---|---|---|
| 1 | 你们做了多久了？ | |
| 2 | 价格为什么是这个？ | |
| 3 | 出了问题怎么办？ | |
| 4 | 有没有保障/退款？ | |
| 5 | 为什么比别人贵/便宜？ | |
| 6 | 什么时候能交付？ | |
| 7 | 我能不能先试一下？ | |
| 8 | 有没有参考案例？ | |
```

## 3. YouTube 预型物料

### 3.1 分镜脚本

```
【片长】90～150 秒（超过 2 分钟完播率显著下降）
【铁律】点赞和浏览量不算数据。结尾必须有切身利益动作。

| # | 时长 | 画面 | 旁白 | 目的 |
|---|---|---|---|---|
| 1 | 0-8s | {痛点场景：展示现状的糟糕} | "如果你 {目标人群特征}，你可能遇到过 {具体痛点}。" | 建立共鸣 |
| 2 | 8-20s | {产品出现} | "{产品} 用 {方法} 解决它。" | 交代价值主张 |
| 3 | 20-50s | {功能演示 1，界面/实物模拟} | "第一步：{动作}。你看，{结果}。" | 展示怎么用 |
| 4 | 50-80s | {功能演示 2，最有说服力的那个} | "{最有冲击力的收益，带数字}。" | 峰值 |
| 5 | 80-100s | {使用场景，真实环境} | "早上 {时间}，{谁} 打开它……" | 想象自己 |
| 6 | 100-120s | {价格 + CTA 画面} | "{价格}。现在预订，{动作}。" | **收割切身利益** |
| 7 | 120-135s | {坦白/免责字幕} | "这款产品仍在开发中……" | 合规 |
```

**软件类的最佳实践**：用 Keynote / PPT 做界面模拟图（每页一个用户动作），组合成动画，看起来就像能用的应用。**一行代码都不用写。** 文中 FeeBird 案例里，作者用 10 分钟做完了两张界面图。

**视频必须满足"可让人投入切身利益"的要求**，可选 CTA：

| CTA | 对应的切身利益 | 强度 |
|---|---|---|
| 提交邮箱接收上线通知 | 1 点/个 | 低 |
| 加入候补名单（留电话） | 10 点/个 | 中 |
| 观看 30 分钟 webinar | 30 点/个 | 中 |
| 支付 ¥N 订金 | N 点/个 | **高** |
| 支付全款预购 | 全额点数 | **最高** |

**警告（来自谷歌眼镜案例）**：
> 对于某些产品，初期的关注和承诺是必要的，但**仍不足以判断该产品是否是"正确的它"**，因为一种产品和服务的成功取决于人们**反复的使用和持续的参与**。

因此视频预型之后**必须**跟进一个复购/持续使用测试（如一夜情预型或假面预型），否则你只测到了"兴奋"，没测到"留存"。

### 3.2 旁白与结尾 CTA 文案范式

> 如果你现在 **{使用着某个糟糕的替代方案}**，那这条视频就是给你的。
>
> {产品} 做到了一件事：**{核心收益，带数字}**。

## 4. 一夜情预型物料

### 4.1 宣讲会提纲（60 分钟）

```
【0-5 min】钩子
  直接抛出最反常识的那个数字或结论。不要铺垫。

【5-15 min】问题定义
  让听众确认"这确实是个问题"。
  "在座有多少人 {痛点行为}？举手。" （举手 = 0 点，仅用于暖场）

【15-35 min】方案演示
  现场演示/模拟。这是唯一能让人相信的环节。
  如果方案可用人工模拟，就现场模拟（土耳其机器人）。

【35-45 min】价格与承诺
  明确报价。明确交付时间。明确退款政策。
  ⚠️ 不要说"大概""看情况""视人数而定"——这会让数据模糊化。

【45-55 min】收集切身利益
  现场报名 / 扫码留电话 / 付定金。
  "现在扫码登记，今天到场的人享 {具体优惠}"。

【55-60 min】Q&A + 记录
  记录所有被问到的问题——它们告诉你市场在担心什么。
```

### 4.2 报名邮件

```
主题：{具体收益带数字} — {日期} 现场，限 {N} 人

{称呼}：

我在 {公司/社区} 认识了 {推荐人}，他提到你 {与目标人群相关的特征}。

{日期} {时间}，我在 {地点} 做一场 60 分钟的分享，讲 {主题}。
不是产品销售会，是 {产品} 的可行性测试——我想知道这件事到底有没有人真的需要。

你可以得到：
· {具体内容 1}
· {具体内容 2}
· {具体内容 3}

价格：¥{价格}（现场支付 / 预付链接）
如果最终没做成，全额退款。

座位只有 {N} 个，回复本邮件或点这里登记：{链接}

{署名}
```

**关键设计**：邮件里必须**明说价格**。BusU 案例中第一次试验就因为没提 3 000 美元价格，导致 62% 的回应数据被"以为免费"污染，只能保守下调一档。

### 4.3 定金页文案

```
锁定价位：¥{订金}（总价 ¥{全价} 的 {百分比}%）

你现在支付的 ¥{订金} 会：
✓ 锁定 ¥{全价} 的首发价格（正式上线后为 ¥{涨价后价格}）
✓ 让你进入 {N} 人 的优先名单
✓ 如果 {产品} 最终没有上线，{N} 个工作日内全额退回，不需要理由

我们为什么要收订金？
因为我们需要知道有多少人是真的要，而不只是说"听着不错"。
订金是唯一诚实的答案。

[立即支付 ¥{订金}]
```

## 5. 潜入者预型物料（合规版）

### 5.1 商户合作邀约

```
主题：一个不占用你库存的展示试验 —— 我们付你 ¥{金额}

{店主姓名} 你好：

我是 {姓名}，在做 {产品}。我想测试它在 {你的品类} 门店里的真实表现，
而不是靠问卷问顾客"你会不会买"。

**我提议的是**：
· 我把 {N} 件 {产品} 放在你店里 {时长}（位置由你定）
· 我付你 **¥{金额}**，现在就能先付
· 货架上的每笔"售出"都归你——顾客想付钱时，收银台正常收，收入全归你
· 试验结束后我把剩余样品带走，不留任何库存给你

**我需要记录的是**：多少人拿起来看、多少人拿到收银台。
我会在旁边 {位置} 用手机记录，不打扰你的生意，也不冒充你的员工。

如果结果好，我们再谈正式的供货合作；如果不好，你白赚 ¥{金额}，我也不吃亏。

方便的话，我这周来店里聊 10 分钟？

{署名}
```

**⚠️ 与原书案例的区别**：书中贾斯汀·波卡诺的做法是买二手宜家员工服、假扮宜家员工、偷偷把产品摆进宜家货架。**本 skill 一律不采用该做法**——那是个人承担风险的行为，且可能惹出法律麻烦。合规版本是**付费租用个体商户的展示位**，光明正大地做。

### 5.2 陈列与记录方案

```
【位置选择】按客流路径排序，依次测试：
  1. 入口/收银台附近（曝光最高，干扰也最大）
  2. 与同类商品相邻的货架（意图最匹配）
  3. 纵深区域的独立展示（停留时间最长）

  每个位置至少测 {N} 小时，同一时段（如都是周末上午）才可比较。

【记录表】
| 时段 | 位置 | 路过人数 | 拿起查看 | 拿到收银台 | 实际付款 | 备注 |
|---|---|---|---|---|---|---|
| | | | | | | |

【观察要点】
· 拿起后看价格的反应（皱眉 / 放下 / 放回原处 → 价格偏高）
· 拿起后翻看包装的时长
· 是否询问店员（如有，记录问了什么）
· 同行者是否影响决定
```

### 5.3 线上版本

```
给 {在线零售商} 的合作提议：

你的客户里已经有 {N} 人买过 {同类产品}。我想在你的店铺里上一个新品测试页，
为期 {时长}，测完就下架。

条件：
· 试验期间的所有销售收入**全部归你**
· 另外我再付 ¥{金额} 作为展示位租金
· 你的客户数据我一个都不留，我只统计 {页面浏览 → 加购 → 下单} 的转化数字
· 页面上会明确标注"正在测试中"，不会冒充你的自有商品

如果你愿意，我这周把商品页素材发给你过目。
```

> 通常来说，**跟小公司打交道要比跟大企业打交道更容易**，也更容易进行这类试验的合作。

## 6. 改标签预型物料

### 6.1 标签设计要点

| 要素 | 要求 |
|---|---|
| **名称** | 必须与原产品名称形成明确对比（如"隔日寿司：半价"） |
| **价格** | 与对照组形成倍数关系，而非细微差异 |
| **位置** | 与原产品同货架、同层、同高度 |
| **数量** | 对照组与实验组各占 50%，随机交替摆放 |
| **合规** | 不得涉及虚假的营养/健康/安全声明 |

**可结合潜入者预型**：借用现成的产品和已被验证的客户群体，成本极低。

### 6.2 记录表

```markdown
## 改标签试验记录表

**对照组**：{原产品，N 件}  **实验组**：{改标签产品，N 件}
**时段**：__  **地点**：__

| 项目 | 对照组 | 实验组 |
|---|---|---|
| 上架数量 | | |
| 售出数量 | | |
| 售出率 | | |
| 时段内总客流 | | |

**实验组售出 / 总售出 = __%**（假说判定线：≥__%）

**异常记录**（务必记录——这决定了数据能否使用）
- 当天是否有媒体相关报道：
- 是否有特殊人群出现：
- 天气/节假日/特殊活动：
- 其他可能影响结果的因素：
```

**异常记录的重要性**：隔日寿司案例中，两次被污染的数据分别是——当天学校日报刊登了生鱼片风险的头版文章（成果 F，降级为 50/50）、试验当天来了一大群参加大学旅行的日本高中生（成果 G，直接丢弃）。**不记录这些，你会把污染数据当成真信号。**

## 7. 合规检查清单（投放前必过）

```markdown
### 通用
- [ ] 目标是收集**切身利益**，而不是点赞/关注/浏览量
- [ ] 记录字段包含曝光数、目标动作数、目标动作者画像
- [ ] 已准备异常记录表（用于事后判断数据是否可用）

### 假门专项
- [ ] 品类**不涉及**医疗、健康、金融、人身或财产安全
      → 若涉及，**必须改用假面预型**
- [ ] 已准备坦白文案，并指定了补偿物
- [ ] 若涉及任何预付金额，已写明全额退款条款与时限

### 潜入者专项
- [ ] **没有**假冒他人雇员
- [ ] **没有**未经许可将产品摆入他人卖场
- [ ] 采用付费租用个体商户展示位的合规方式
- [ ] 已与商户书面确认合作范围与费用

### 物料专项
- [ ] 落地页首屏明示价格（避免 BusU 式污染数据）
- [ ] 广告 A/B 变体只改一个变量
- [ ] 视频结尾 CTA 对应真实的切身利益动作
- [ ] 所有物料中不出现"大概""看情况""视人数而定"等模糊表述

### 数据专项
- [ ] 样本量 ≥100（有统计意义）
- [ ] 样本来自目标市场 Y 的代表性人群，而非朋友/家人/同事
- [ ] 已规划至少 3～5 次试验，而非单次
```
